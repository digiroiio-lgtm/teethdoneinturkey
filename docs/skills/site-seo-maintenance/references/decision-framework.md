# Keep / Improve / Merge / 301 / Noindex / Remove

Never decide from one metric. Rule out first: page < 90 days old, seasonal, weak internal links, indexing/canonical fault.

NOINDEX or MERGE needs most of these together: 0 clicks; very low impressions; no independent keyword intent; no unique local/first-party info; high similarity to another URL; no backlinks; no conversions.

Four questions per URL:
1. Does it have an independent search intent?
2. Is there unique information that justifies being indexed?
3. Does another URL do the job better?
4. Which of improve / merge / noindex adds the most total site value?

| Action | When |
|---|---|
| KEEP | clicks, impressions, backlinks, conversions or strong distinct intent |
| IMPROVE | intent right, content thin/generic |
| MERGE | same intent as another URL; fold unique parts into the stronger one |
| 301 | merged AND same intent AND largely same info AND cannibalizing. Same entity ≠ same intent (cost / rent aid / application of one city are separate intents → keep as cluster) |
| NOINDEX | useful to users, no standalone search value |
| REMOVE (404/410) | obsolete, no replacement needed |

On 301/merge: update every internal link to the target in the same change and drop dead sitemap overrides.
Success is not a smaller index: 1,150 → 650 URLs with rising impressions and non-brand clicks is healthy.
